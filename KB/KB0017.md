# Hardware: external monitor not detected
Category: Hardware

## Symptoms
Your external Dell or LG desk monitor stays black and displays "No USB-C / DisplayPort Signal" when connected to your `PVP-LT-*` laptop or `PVP-Dock-G4`.

## Cause
The `PVP-Dock-G4` Thunderbolt display controller needs a power reset, or the monitor's input source is set to HDMI instead of DisplayPort/USB-C.

## Steps
1. Press the physical input button on the bottom bezel of the monitor and manually select **DisplayPort (DP)** or **USB-C**.
2. Unplug the power barrel cable from the back of the `PVP-Dock-G4` docking station for 15 seconds, then plug it back in.
3. Press **Win + P** on Windows and select **Extend** to force display detection.
4. Open **PVP AppStore**, run **PVP-Dock G4 Firmware & DisplayLink Updater**, and reboot if prompted.

## If it still fails
Test with a spare cable from an adjacent workstation; if still blank, submit a ServiceNow ticket under **PVP Workplace > AV-DeskSetup** with your desk ID (e.g., `DESK-HYD02-314`).
