# Software: install software from the PVP AppStore
Category: Software

## Symptoms
You need an approved application such as VS Code, Postman, Docker Desktop, or 7-Zip, but Windows blocks the `.exe` installer with a UAC administrator prompt.

## Cause
Standard PVP Corp users do not hold local administrator privileges; approved applications must be deployed via **PVP AppStore** (`Intune/SCCM`).

## Steps
1. Confirm you are connected to `PVP-Corp-5G` or **PVP-SecureConnect**.
2. Open the Start menu, type **PVP AppStore** (or **PVP Self Service** on macOS), and launch the portal.
3. Search for the required application in the catalog and click **Install**.
4. Keep the window open for 5–10 minutes while `PVP-EndpointAgent` downloads and silently installs the signed package.
5. If a package is labeled **Approval Required**, click **Request** to route an automated approval task to your manager.

## If it still fails
Submit a ServiceNow ticket under **PVP EndUserComputing > AppPackaging-Support** with the application name, version, and `C:\ProgramData\PVPAppStore\install.log`.
