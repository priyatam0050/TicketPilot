# Network: Wi-Fi keeps dropping in the office
Category: Network

## Symptoms
Your laptop repeatedly disconnects from `PVP-Corp-5G` every few minutes when moving between meeting rooms or sitting near glass partitions, forcing **PVP-Chat** and calls to reconnect.

## Cause
Aggressive Wi-Fi roaming sensitivity on the Intel wireless adapter is clinging to a distant ceiling access point (`AP-HYD-*`) instead of switching to the nearest node.

## Steps
1. Open **Device Manager** from the Start menu and expand **Network adapters**.
2. Right-click **Intel(R) Wi-Fi 6E AX211** and select **Properties > Advanced**.
3. Select **Roaming Aggressiveness** and change the value from `3. Medium` to `4. Medium-High`.
4. Open Command Prompt as administrator and run `ipconfig /flushdns` followed by `netsh wlan delete profile name="PVP-Guest"` so your laptop does not fall back to the visitor network.
5. Toggle Wi-Fi off and back on to bind to the nearest `PVP-Corp-5G` access point.

## If it still fails
Raise a ServiceNow incident under **PVP Network > Campus-Wireless**. Include your building code (e.g., `BLD-HYD-02`), floor, nearest pillar ID, and the MAC address of your Wi-Fi adapter.
