# VPN: fix error 809 when working from home
Category: Network

## Symptoms
Users see a pop-up stating "Error 809: The network connection to `vpn-gw.pvpcom.internal` could not be established because the remote server is not responding" inside the **PVP-SecureConnect** client while on home Wi-Fi or a mobile hotspot.

## Cause
The home router or ISP is blocking UDP ports 500 and 4500 required for PVP Corp's legacy L2TP gateway, or the `PVP-TAP-v9` virtual adapter is stalled.

## Steps
1. Open the **PVP-SecureConnect** client, click the gear icon, and change the gateway profile from `PVP-Legacy-L2TP` to `PVP-SSL-ZeroTrust (vpn2.pvpcom.com)`.
2. Click **Connect** and approve the push notification in the **PVP-Guard MFA** app.
3. If `PVP-Legacy-L2TP` is required for legacy ERP access, open **Device Manager**, expand **Network adapters**, right-click **PVP-TAP-v9 Virtual Adapter**, and select **Uninstall device**.
4. Reboot your laptop to trigger the `PVP-EndpointAgent` auto-repair script, then retry connecting.

## If it still fails
Submit a ServiceNow ticket under **PVP Network > NetOps-VPN-Tier2**. Include your home ISP name, a screenshot of the `PVP-SecureConnect` log (`C:\ProgramData\PVPNet\vpn.log`), and whether a phone hotspot works.
