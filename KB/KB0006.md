# Network: cannot reach internal sites (DNS resolution failure)
Category: Network

## Symptoms
Public websites like Google load normally, but internal portals (`jira.pvpcom.internal`, `intranet.pvpcom.internal`, `myapps.pvpcom.com`) show "DNS_PROBE_FINISHED_NXDOMAIN" or "Server IP address could not be found."

## Cause
Your adapter is using a public DNS server (`8.8.8.8` or `1.1.1.1`) instead of PVP Corp's internal Infoblox DNS resolvers (`10.240.10.53` and `10.240.10.54`).

## Steps
1. Confirm **PVP-SecureConnect** is connected if you are working remotely.
2. Open Command Prompt as administrator and run `nslookup intranet.pvpcom.internal` to check which DNS server responds.
3. If an external DNS IP appears, open **Control Panel > Network and Sharing Center > Change adapter settings**.
4. Right-click your active adapter (or **PVP-TAP-v9**), select **Properties > Internet Protocol Version 4 (TCP/IPv4)**, and set both IP and DNS to **Obtain automatically**.
5. Run `ipconfig /flushdns` in Command Prompt and reload the internal site.

## If it still fails
Log a ServiceNow incident under **PVP Network > Infoblox-DNS-Support**. Paste the full output of `ipconfig /all` and `nslookup intranet.pvpcom.internal` into the ticket description.
