# Access: new joiner account and system setup
Category: Access

## Symptoms
A new hire starts today or this week and lacks an `@pvpcom.com` email address, `myapps.pvpcom.com` login, or standard department applications.

## Cause
The hiring manager has not completed the pre-hire task in Workday, or the automated `PVP-IAM-Sync` job has not yet provisioned their Active Directory object.

## Steps
1. Verify in **Workday** (`https://workday.pvpcom.com`) that the new hire's start date, cost center, and hiring manager fields are marked **Approved**.
2. Wait for the automated `PVP-IAM-Sync` cycle (runs every 2 hours) to create the `username@pvpcom.com` account and assign base `SG-ROLE-*` groups.
3. On Day 1, the hiring manager must retrieve the initial temporary password from **PVP-AccessHub > My Direct Reports > Onboarding Credentials**.
4. Have the new hire sign into their `PVP-LT-*` laptop, set a permanent 14-character password, and register **PVP-Guard MFA** at `https://myapps.pvpcom.com/security-info`.

## If it still fails
Submit an urgent ServiceNow request under **PVP Identity > Onboarding-Provisioning** or call `ext. 4357` with the new hire's `Workday-ID`, start date, and manager's `PVP-EmpID`.
